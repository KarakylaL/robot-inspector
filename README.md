# 🤖 Робот-инспектор

Учебный проект мобильного робота, созданный для изучения робототехники,
программирования микроконтроллеров, датчиков, сетевого взаимодействия,
Python и баз данных.

Робот-инспектор перемещается по помещению, контролирует расстояние до
препятствий и собирает информацию об окружающей среде с помощью нескольких
датчиков.

Полученные данные передаются на компьютер по Wi-Fi, где специальная программа
на Python отображает их в реальном времени и сохраняет в базу данных
PostgreSQL.

---

## 🎯 Цель проекта

Главная цель проекта — показать, как отдельные элементы робототехнической
системы объединяются в единое целое.

В процессе работы мы познакомимся с:

- микроконтроллерами;
- датчиками;
- электродвигателями;
- аналоговыми и цифровыми сигналами;
- последовательной передачей данных;
- Wi-Fi и TCP;
- программированием на C/C++;
- программированием на Python;
- графическим интерфейсом;
- PostgreSQL;
- хранением и анализом данных.

---

## 🤖 Что умеет робот

Робот:

- двигается с помощью двух двигателей;
- измеряет расстояние до препятствий;
- останавливается перед препятствием;
- измеряет температуру;
- измеряет влажность;
- контролирует уровень газа;
- измеряет освещённость;
- контролирует датчик огня;
- передаёт показания датчиков на компьютер.

Если расстояние до препятствия становится меньше установленного безопасного
значения, двигатели останавливаются.

---

## 🔬 Датчики

В проекте используются следующие датчики:

| Датчик | Назначение |
|---|---|
| DHT11 | Температура и влажность |
| HC-SR04 | Измерение расстояния |
| Газовый датчик | Контроль уровня газа |
| Датчик освещённости | Измерение освещённости |
| Датчик огня | Обнаружение источника огня |

Аналоговые датчики подключены к аналоговым входам контроллера.
